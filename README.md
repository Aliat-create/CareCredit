# اعتبار سلامت

A standalone Next.js 15 PWA demo for an Iranian healthcare BNPL workflow.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## GitHub upload

1. Create a new GitHub repository.
2. In this folder, run `git init`.
3. Add the files and commit.
4. Push to the repository URL.

## Vercel deploy

1. Open Vercel and choose **New Project**.
2. Import the GitHub repository.
3. Keep the default framework detection on Next.js.
4. Deploy with one click.

## Included demo flow

- Landing page for `اعتبار سلامت`
- Installment calculator
- Mobile OTP simulation
- Shahkar verification simulation
- Video KYC and liveness simulation
- Credit scoring engine
- Patient dashboard with invoices and calendar
- Clinic portal with invoice issuing flow
